Mission

To document every milestone of TechPro B's journey in a format as forward-looking as the students themselves — searchable, interactive, and built to last well beyond graduation day.

Vision

A yearbook that feels less like a book and more like a place — one classmates can return to, explore, and add to for years to come.

Description

TechPro B Digital Yearbook is an interactive archive built by and for the graduating IT class of 2026. It combines a photo gallery, a hall of fame, a message wall, and an AI guide named Luminara into a single holographic-styled experience — a keepsake designed to be revisited, not just read once.
